## 一、这组截图好在哪（提炼）

1. **半模态是「一块温暖的玻璃」，不是一张白纸**
   通体一个大圆角（约 32）容器，没有边框、没有分割线；层级全靠**嵌套浅井**拉开：
   输入框 / 备注 / 详情块都是同底色再深一档的圆角块（约 16），块与块之间 12。
2. **胶囊分组成对出现**
   左侧「文件夹 / 分类 / 星标」一组、右侧「提醒 / 日期」一组：都装在同色的胶囊容器里，
   组内 4，组间靠 justify-between 拉满整行；胶囊高约 36、圆角 full。
3. **可展开行（disclosure row）**
   图标 + 文案在左、chevron 在右，行高 48~56；展开后在**同一行下方缩进**铺内容
   （时间/重复/按钮对），缩进量与左图标列宽对齐 —— 视觉上「这是上面那一行的细节」。
4. **弹层（popover）是贴着触发点的白卡**
   圆角 20、行高 48、右侧放勾选或色点、行间用 1px 细分隔线而不是空隙；
   列表项多时给滚动，高度上限约为屏幕的 1/2。
5. **浮起的「进行中」胶囊**
   渐变描边的胶囊（左侧图标徽章 + 主文案 + 时间胶囊 + 右侧箭头），是「当前这一条」的
   唯一高点，其余内容全部退到背景里。适合 Rein 的「进行中的待办 / 正在训练 / 番茄钟」。
6. **底部悬浮分段导航**
   整条胶囊容器内 icon+label，选中项只换颜色（accent）不换底；右上角不堆操作。
7. **数字步进器 / 分段切换 / 原生弹窗**
   步进器是「圆形 − / + + 中间数字」，圆钮 32；分段切换是胶囊容器内的两段；
   系统弹窗是「居中图标 + 粗标题 + 正文 14 + 两个文字按钮 + 竖分隔线」。
8. **配色纪律**：暖中性底（不是纯白/纯灰），单一强调色（暖黄），
   文字三级（主 / 次 / 说明）不靠字号堆层级。

## 二、映射到 Rein 的组件（施工条目）

| 参照 | Rein 组件 | 要落的具体做法 |
|---|---|---|
| 半模态整体 | SheetModal / ActionSheet / SmartAddSheet | 容器圆角 32（桌面 24）；内容左右 16；**内部块用 --surface-inset 浅井 + radius 16 + padding 12**，块间 12；不放分割线 |
| 输入框贯通行 | TodoEditorSheet / GrabTaskEditSheet / 各 FormSheet | 标题输入做成整行浅井（radius 16、左右 16、高 ≥ 48）；行尾放图标按钮（34 圆钮）而不是文字 |
| 胶囊分组 | PillChip / StatusChip 组 | 同组间距 4、容量胶囊高 24~28、圆角 full、组与组之间撑满（space-between） |
| 可展开行 | TodoEditorSheet 的「子任务 / 时间 / 地点」类设置行；AppMenu 分组 | 行高 48、图标 20、文字 14~16、chevron 右对齐；展开内容左缩进 32、内部行高 44~48、标签 12 在控件上方 8 |
| 弹层 | AppMenu / ModelPickerSheet / 各类 Picker | 圆角 20、行高 48、行右侧勾选/圆点、行间 1px --line；最大高度 50vh 可滚 |
| 浮起「进行中」胶囊 | FocusFloatBar / ActiveWorkbar / GrabFloatBar / RecordFloatBar | 保持现有渐变/玻璃，只统一：高 44、左右 16、内部图标徽章 32、主文案 14 Medium、右侧箭头 34 圆钮 |
| 底部悬浮分段 | TabBar / GlassDockAssembly | 容器内 icon 24 + label 10~11、gap 2、选中只换 --accent-strong；不额外加底 |
| 数字步进器 | NumberStepper | 圆钮 32、中间数字 16 Medium 等宽、钮与数字 12 |
| 分段切换 | SegmentedControl | 高 28~32、圆角 full、段间 4、选中用 --glass-tab-fill |
| 系统弹窗形态 | ActionSheet 的确认态 / 各类二次确认 | 居中图标 44、标题 20 Bold、正文 14 行高 1.5、两个文字按钮之间 1px 竖线、按钮区高 48 |

## 三、不要照搬的地方

- 参照里的大面积暖黄底、以及「没有关闭按钮」的头部：Rein 有自己的主色与关闭/返回语义，保留。
- 参照的纯不透明卡片：Rein 的高画质档是玻璃材质，**保持玻璃**，只借它的层级与几何。
- 参照的日期大数字（2026/10/19 那种）：仅当页面本来就有大日期时参考其对比度处理，不要新造。
