# UI 对齐施工单（2026-10-21 第二轮）

> 第一轮（`ALIGNMENT.md`）解决的是「值」：把裸 px 换成 4/8 栅格令牌、圆角按层级重排、字号统一。
> 这一轮解决「型」：**同一批数值怎么落到每个页面的结构上**。数值仍以 `ALIGNMENT.md` 为唯一依据，
> 控件形态参考 `CONTROL-REFERENCES.md`，本文只补「落到 Rein 的具体做法 + 验收口径」。

---

## 0. 三条铁律（任何改动都不能破）

1. **只改几何 / 层级 / 排版**：不改文案、不改交互语义、不动玻璃材质与动效语言、不动数据链路。
2. **不碰共享层**：`src/styles/*`、`src/components/common/*`、`src/components/layout/*`、
   `src/components/float/*` 由主线负责。领域内改动若需要共享组件配合，**在报告里写明，不要自己改**。
3. **不新增裸 px**：padding / gap / margin 只用 `--sp-*` / `--gap-*` / `--pad-*`；
   圆角只用 `--radius-*`；字号只用 `--fs-*`。图标尺寸、描边宽度、图表/波形参数不受限。

## 1. 页面级节奏（每页都适用）

| 项 | 口径 |
| --- | --- |
| 屏幕边距 | 手机左右 16（`--pad-page`）、顶部 36、底部留 `--page-pad-bottom`；桌面左右 40 |
| 区块之间 | 24（`--gap-xl`）；同级卡片之间 12（`--gap-md`） |
| 卡片内距 | 16（`--pad-card`）；紧凑卡 12（`--pad-card-tight`） |
| 卡内分组面 | 用 `--radius-m-nest`（12）+ `--surface-2` 浅井，块间 12，**不加分割线** |
| 列表行 | 单行 48、双行 64（`--row-h` / `--row-h-double`）；行内左右 16 |
| 标题层级 | 页面标题 `--fs-large-title`；区块标题 `--fs-title3`/`--fs-headline`；正文 `--fs-body`；说明 `--fs-callout` |
| 数字 | 一律 `.num`（tabular）；单位降一档字重与色阶（`--text-2`），**不跟数字同粗** |
| 色相 | 只出现在图标 / 色点 / 进度条 / 类型字章；文字与数值恒为 `--text-1/2` |
| 对比度 | 正文 ≥7:1、次要 ≥4.5:1、三级 ≥3:1（暗色同样） |

## 2. 组件形态（从 CONTROL-REFERENCES 提炼，按 Rein 现状落）

- **半模态**：容器圆角 32；内容左右 16；内部块用浅井 + 12 圆角，块间 12；标题行与把手 8。
- **行内可展开（disclosure）**：行高 48~56，左侧图标列 20、文案 14~16、chevron 右对齐；
  展开内容左缩进与图标列对齐（32），内部行 44~48。
- **胶囊组**：组内 4、组间 justify-between；胶囊高 24（小）/ 32（可点）；圆角 full。
- **弹层（popover/picker）**：圆角 20、行高 48、行右侧勾选或色点、行间 1px `--line`，最大高 50vh。
- **底部导航**：选中只换色不换底；整条不再叠加额外操作。

## 3. 课表（本轮重点）

### 现状问题（2026-10-21 截图核对）

1. **周视图横向被硬裁**：430 宽下 7 列放不下（列宽 92），右侧整列被切掉一半，
   没有任何「还能横滑」的暗示；初始滚动到本周中段后，左侧也看不到周一，用户不知道自己在哪。
2. **时间列密度过头**：每格两行（`08:00` + `08:40` + `第1节`），10 个时段挤在 320px 里，
   节次标签 10px 灰字几乎不可读；时间与节次两个信息在同一行争注意力。
3. **课程块信息层级弱**：课程名与教师/教室同为深色，块内没有主次；
   长课名在 92px 宽里换行成 3 行并溢出（「计算机组成原理」「大学物理实验」）。
4. **视图切换与日期导航是两套控件**：左侧 segmented（日/周/月）+ 右侧箭头胶囊，
   一个 24 高一个 32 高、圆角不同、贴在一起，读起来是两组无关的东西。
5. **底部两条入口压在内容上**：`nav.links` 挨着网格底边，最后一行课程被它和 Dock 夹住。
6. **今天列只靠文字变蓝**：没有底色/边线，周视图里「今天」不够一眼可见。

### 目标（可验收）

- **周视图**：一屏能读到「今天 + 相邻两天」的完整信息；横向滚动有明确暗示
  （右缘渐隐 + 列宽对齐到列边界，滚动停止后不出现半截列）；今天列有独立的底/边框，
  且表头与网格严格列对齐（同一条列宽变量）。
- **时间列**：只留一行主时间（开始时间，`--fs-caption` `.num`），节次降为次行 10px `--text-3`，
  两行基线 2px（`--gap-text`）；行高一致、分隔用 hairline（`--line`）而不是整块底色。
- **课程块**：色相只在左侧 3px 竖条或左上色点上；块内第一行课程名（2 行截断 + ellipsis），
  第二行「教室 · 教师」单行截断；字号差 ≥2 档、色阶差 ≥1 档；块圆角 12（卡内分组面档）。
- **日期导航**：与视图切换合成一条工具行 —— 同一高度（32）、同一圆角（full/20），
  分段在左、日期步进在右，中间放「本周」快捷（已在本周时不显示）。
- **底部入口**：移出滚动网格的覆盖区（放在唯一滚动容器的内容流末尾，并吃 `--page-pad-bottom`），
  不与最后一节课重叠。
- **空态 / 无课**：区分「还没绑定」「本学期没有」「这一段没有」三种，仍用 `EmptyState` 的口径。
